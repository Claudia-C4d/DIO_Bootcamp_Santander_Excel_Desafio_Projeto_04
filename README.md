# DIO_Bootcamp_Santander_Excel_Desafio_Projeto_04
Desafio de Projeto 04 - Bootcamp DIO Santander Excel com IA e Claude 

Esse material é referente ao Desafio de Projeto “Criando uma Dashboard de Vendas da Porsche com IA” para o curso DIO. Bootcamp Santander Excel com IA, e consiste nos seguintes arquivos:

- DIO_Bootcamp_Santander_Excel_Desafio_projeto_04_criação_dashboard_porsche_IA (Documento em .pdf com o processo de elaboração do projeto)
- dashboard_vendas_porsche_dio_bootcamp_santander.html (página independente HTML)
  
O desafio consiste em criar uma dashboard em HTML com o auxílio de IA a partir de uma base de dados de vendas da Porsche, já tratados, fornecida pela instituição para o projeto do curso.

Foi utilizada a ferramenta de IA Copilot para a criação da dashboard interativa (processo documentado no arquivo em .pdf), e o resultado foi muito bom, mostrando que a utilização de uma ferramenta de IA em projetos com planilhas de dados em Excel pode colaborar significativamente com o resultado pretendido, de maneira simples e intuitiva, gerando nesse caso uma página em HTML independente para ser aberta em qualquer navegador.
